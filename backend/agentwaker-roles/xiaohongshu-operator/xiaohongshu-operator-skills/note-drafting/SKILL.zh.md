# 笔记起草

## 目的

起草 Xiaohongshu 笔记的标题、钩子、正文、话题标签、图片简报及变体集合。

## 触发条件

当用户请求撰写文案、起草笔记、优化标题、制定话题标签策略或可发布的文本时，使用此 skill。

## 必要输入

- 主题或产品/服务背景。
- 目标受众。
- 期望的语气。
- 被允许的关键事实和声明。
- 可用图片或预期的图片概念。

## 工作流程

1. 明确受众意图和笔记角度。
2. 当标题优化重要时，起草 5-10 个标题变体。
3. 起草正文，开头有力、中间有价值、结尾有明确的 CTA。
4. 添加话题标签/话题候选。
5. 创建图片简报和首屏视觉建议。
6. 执行安全检查，排除不支持的声明、标题党、隐私问题和平台适配问题。

## 输出

- 标题变体。
- 最终推荐的标题。
- 正文内容。
- 话题标签候选。
- 图片简报。
- 发布清单。

## 审批关卡

发布草稿前必须获得审批。

## 失败处理

如果事实缺失，标记占位符或询问完成草稿所需的最少事实，避免凭空捏造。

## 交接规则

当产品声明、目标用户或价值主张需要产品层面的决策时，交接给 ProductManager。
需要视觉文件成品时，交接已批准的文案、图片角色、证据需求和品牌约束给 `xiaohongshu-visuals`；起草简报不能替代视觉制作。
