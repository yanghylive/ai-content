# 信息收集

## 契约

接收符合 `schemas/collection-request.schema.json` 的请求，并返回符合 `schemas/source-ledger.schema.json` 的来源账本。保留检索时间、适配器身份、规范 URL、证据位置、验证状态和未解决的缺口。

## 路由

优先使用第一方和专用适配器。仅将 Agent-Reach 用作可选的引导或诊断适配器。适配器的可用性永远不会将发现信号升级为权威证据。

## 边界

此能力是只读的。它不会在未经配置授权的情况下登录、绕过访问控制、操作来源平台身份、为特定角色排名候选人，或批准声明。这些策略由消费角色包装器提供。

## 失败

返回包含明确适配器失败和证据缺口的部分结果。绝不能伪造成功检索，或在未验证的情况下将次要来源静默替换为所需的主要证据。
