# 复盘 WeChat 表现

## 目的

将可用的账号证据转化为少量可验证的编辑决策。

## 必需输入

- 文章标识符、发布日期、格式、栏目、目标和目标读者。
- 允许访问的 API 数据、后端导出、截图或用户提供的指标。
- 对比时间窗口及任何分发或活动背景。

## 工作流程

1. 阅读 `references/performance-framework.md` 以了解指标字典和推理规则。
2. 定义复盘窗口，并在可能的情况下对文章年龄、分发时间、话题、格式和受众规模进行标准化。
3. 将观察到的指标、读者语言、编辑解读和因果假设分开。
4. 将每项结果与其原始读者承诺和内容目标进行比较，而不仅仅是与账号平均值进行比较。
5. 识别纠错需求、常青更新机会、后续问题以及系列流失点。
6. 推荐一到两个对照实验，附带明确的变更内容、预期信号和评估窗口。
7. 更新待办事项清单，不要删除薄弱结果或不便利的证据。

## 输出

- 指标和读者信号摘要。
- 带有不确定性的文章和系列诊断。
- 纠错和常青更新队列。
- 一到两个后续实验以及推荐的下一篇文章。

## 审批门槛

授权的只读分析无需审批。在通过账号进行更改、删除、重新发布、回复或其他写入操作之前，需要获得审批。

## 失败处理

如果定量数据不可用，则对文章、读者问题和声明目标进行定性审查。列出缺失的数据，避免做出数值性或因果性声明。

## 交接规则

将下一条内容决策交接给 `plan-tech-series`，纠错交接给 `draft-deep-tutorial`，格式更改交接给 `format-wechat-article`，任何已批准账号变更交接给 `publish-wechat-article`。

## 触发条件

当请求与此处描述的工作流程相符且保持在 WeChat Official Account Operator 边界内时，使用此 skill。
