# 「我的」页面 WorkBuddy 化改造方案

- 日期：2026-09-01
- 范围：桌面端 `/mine` 与 `/settings/*` 的页面形态重构（信息架构 + 布局）
- 参考对象：WorkBuddy（腾讯云 CodeBuddy 桌面版）设置中心

---

## 1. 背景与目标

当前「我的」页面（`/mine`）是**卡片网格**形态（ScenePage 资料卡 + 分组卡片：账号与设置 / 设置 / 系统与服务），
上一轮已把设置收编进「我的」并拆出 8 个独立入口，但页面本身仍是"铺卡片"的浏览形态。

WorkBuddy 的设置中心采用 **macOS 系统设置式双栏**：左侧分组导航（通用 / 对话 / Tab / 文档），
点击切换右侧内容面板；入口为右上角头像 → 设置。

**改造目标**：把「我的」+「设置」整合为一个 WorkBuddy 式的**设置中心**——
左栏分组导航常驻、右栏内容随导航切换，减少来回跳转，功能查找更快。

---

## 2. WorkBuddy 参考特征（已确认）

1. **入口**：右上角头像 → 设置（九章当前 rail 底部「我的」按钮即入口，可保留）。
2. **设置页布局**：左侧导航菜单 + 右侧内容区，左侧分组：通用、对话、Tab、文档。
3. **导航项形态**：图标 + 名称的列表行，选中态高亮，分组有小标题。
4. **账号能力**：头像下方显示账号信息，设置项含换绑手机号、记忆库、我的分享等。
5. **交互**：左栏点击即时切换右栏内容，无页面跳转感。

---

## 3. 现状与差距

| 维度 | 现状（九章 /mine） | WorkBuddy 风格 | 差距 |
|------|------------------|----------------|------|
| 布局 | 卡片网格铺开 | 左导航 + 右内容双栏 | 需重构 |
| 导航 | 无（靠卡片点击跳子页） | 左侧常驻分组导航 | 需新增 |
| 选中态 | 无 | 左栏高亮当前项 | 需新增 |
| 内容切换 | 整页跳转 | 右栏原地切换 | 需调整 |
| 搜索 | 无 | 设置搜索（可选） | 可选增强 |
| 账号区 | 顶部资料卡 | 左栏顶部账号区 | 需对齐 |

## 4. 目标信息架构（推荐方案）

### 4.1 整体布局（桌面 ≥768px）

```
┌─────────────────────────────────────────────────────────────┐
│ kx-topbar（搜索 ⌘K / 工作区 / 通知）                          │
├───────────────┬─────────────────────────────────────────────┤
│ rail（业务导航）│  kx-page-head：设置中心（面包屑：我的 › 设置中心）│
│ 今日增长       │ ┌──────────┬──────────────────────────────┐ │
│ 获客中心       │ │ 左栏导航    │ 右栏内容区（children）        │ │
│ 客户管理       │ │ ┌──────┐ │ ┌──────────────────────────┐ │ │
│ 内容运营       │ │ │账号区 │ │ │ 当前导航项对应的设置面板     │ │ │
│ 互动中心       │ │ │ 头像/名│ │ │ （个人资料 / 通知 / AI 服务  │ │ │
│ 执行中心       │ │ │ 套餐/分│ │ │  / 桌面 / 数据 / 合规…）    │ │ │
│ 设备任务       │ │ └──────┘ │ └──────────────────────────┘ │ │
│ ──────────    │ │ 搜索设置框 │                              │ │
│ 助手 / 我的     │ │ 分组A 条目 │                              │ │
│               │ │ 分组B 条目 │                              │ │
│               │ └──────────┘                              │ │
└───────────────┴─────────────────────────────────────────────┘
```

### 4.2 左栏导航分组（源自 nav-registry，禁止手写第二份）

| 分组 | 条目（key → 路由） | 说明 |
|------|-------------------|------|
| 我的概览 | 个人主页 `/mine` | 资料卡 + 权益 + 用量（现有 /mine 保留） |
| 账号与设置 | 平台账号 `/distribution/accounts`、多账号矩阵 `/accounts-matrix`、账号与团队 `/capabilities/account` | 沿用现有卡片条目 |
| 设置 | 账号与安全 `/settings/account`、通知 `/settings/notifications`、显示 `/settings/appearance`、AI 服务与存储 `/settings/integrations`、桌面 `/settings/desktop`、数据 `/settings/data`、合规 `/settings/legal` | 上一轮已拆分 |
| 系统与服务 | 电脑本机服务 `/local-engine`、应用与安装 `/apps`、任务证据 `/tasks/evidence`、记忆设置 `/settings/memory`、引擎权限 `/local-engine/permissions`、数据用量 `/intelligence/costs`、商业就绪 `/commercial-readiness` | 沿用 |

### 4.3 右栏内容策略（两种方案）

- **方案 A（推荐）· 嵌套路由 + layout**：新建 `/settings/layout.tsx` 双栏壳，左栏常驻，
  右栏渲染 children；导航即路由跳转（URL 可刷新/可分享/可后退），落地成本低、与既有子路由天然对齐。
- **方案 B · 单页状态切换**：/mine 内 state 切换右栏，无跳转感但 URL 不深链、需自管理各面板组件。

> 推荐 A：上一轮已产出 6 个独立子路由与公共区块组件（settings-sections.tsx），
> 复用它们即可，避免维护两套渲染逻辑。

## 5. 视觉规范（沿用现有主题，不引入新设计系统）

- 左栏：`kx-view` 内嵌双栏，左栏固定 `240px`，`kaypal-v3-panel` 玻璃卡；
- 导航项：图标（ShellIcon 18px）+ 标题 + 描述（可选），`hover` 浅紫底、选中品牌紫 `--kaypal-v3-accent-soft` 底 + 左侧 3px 品牌紫指示条；
- 分组标题：`text-xs` `--kaypal-v3-muted` 加粗，组间留白；
- 账号区：左栏顶部小资料卡（头像圆形渐变、昵称、套餐徽标、积分、退出），与 WorkBuddy 头像入口对齐；
- 右栏：复用现有 `V2Section` / 公共区块组件，暗色模式由全局 token 自动适配（白卡片问题已修复）。

---

## 6. 响应式

- **桌面 ≥768px**：双栏（左 240px + 右自适应）。
- **移动端 <768px**：保持现有 `mx-*` 列表形态（已接近 WorkBuddy 列表感），不套双栏；
  仅把分组标题加粗对齐、头像行加入口感。移动端零改动或微调。

---

## 7. 实施步骤（P0 / P1 / P2）

### P0 · 双栏骨架（核心价值）
1. 新建 `src/app/(dashboard)/settings/layout.tsx`：
   - 左侧导航组件（数据源：`nav-registry.ts` 的 `MINE_NAV_ENTRIES` 按 `group` 分组）；
   - `usePathname()` 高亮当前项；选中项品牌紫指示条；
   - 顶部"返回我的"与账号区；
   - 右栏 `<main>` 渲染 `children`。
2. `/settings` 聚合页降级为"设置中心首页"（保留现有区块摘要或改为引导卡）。
3. `sceneOfPath` 无需改动（`/settings` 已归 mine）。

### P1 · 体验对齐
4. 左栏顶部加"搜索设置"（过滤左栏条目，纯前端过滤即可）。
5. `/mine` 页保留资料卡 + 权益 + 用量概览，与左栏"我的概览"呼应；
   rail「我的」按钮仍指向 `/mine`，`/mine` 顶部加"进入设置中心"主按钮。
6. 命令面板（⌘K）条目与左栏同步（已部分完成）。

### P2 · 打磨
7. 空态/加载态、键盘上下键导航左栏、`aria-current` 无障碍。
8. 移动端分组标题样式微调。

## 8. 验收标准

- [ ] 桌面「我的」与「设置」可在一个左栏内到达全部 8+ 项，无需来回返回；
- [ ] 左栏选中态跟随 URL（刷新/前进后退不丢失）；
- [ ] 右栏内容与对应子路由一致（复用 settings-sections.tsx，无重复逻辑）；
- [ ] 暗色模式无白卡片回归；移动端列表不受影响；
- [ ] `npm run typecheck`、`navigation:zero-loss`、`build` 全绿。

## 9. 风险与权衡

| 项 | 说明 |
|----|------|
| 左栏高度 | 条目较多时左栏可滚动（`overflow-y-auto`），分组标题吸顶可选 |
| /settings 聚合页 | 改造成双栏后聚合页角色弱化 → 作为"设置中心首页"展示摘要或直接重定向到账号与安全 |
| 工作量 | P0 约 1 个 layout + 1 个导航组件 + 少量样式，改动集中在 shell/settings 两层，风险低 |
