AI Content 账号协作 E2E 验收清单

这份清单配合 scripts/assisted-e2e-acceptance.mjs 使用。目标是让用户提供真实账号登录、扫码和确认，但脚本本身不擅自真实发送评论、私信、微信消息，也不擅自发布图文或视频。

安全边界：脚本只推进到登录检查、任务创建、草稿生成、待确认、失败恢复、证据导出。所有真实发送/发布动作必须由用户在界面里明确确认，脚本不会自动批准发布确认。

运行命令

cd "/Users/yanghy/Documents/New project/ai-content"
FRONTEND_URL=http://localhost:3010 \
API_BASE=http://localhost:3011/api \
node scripts/assisted-e2e-acceptance.mjs

无人值守安全链路可用：

ASSISTED_E2E_AUTO=1 \
SMOKE_USERNAME=$COMMERCIAL_USERNAME \
SMOKE_PASSWORD=$COMMERCIAL_PASSWORD \
FRONTEND_URL=http://localhost:3010 \
API_BASE=http://localhost:3011/api \
node scripts/assisted-e2e-acceptance.mjs

需要用户协作的节点

节点 用户要做什么 脚本会做什么 脚本不会做什么
主系统登录 输入 Kaypal/AI Content 账号密码。 等待登录后继续检查导航和 API。 不保存账号密码。
平台账号登录 在发布中心的平台账号页扫码或刷新抖音、小红书、B 站、视频号账号。 读取账号列表和登录态，继续创建受控发布确认。 不点击真实发布。
微信桌面登录 打开本机微信，登录测试账号，把测试联系人或测试群放到前台。 检查微信会话状态，创建微信草稿任务。 不点击微信发送按钮。
评论/私信验收 如要真实平台预检，提供可用平台账号并保持登录。 创建评论、私信任务，验证是否停在待确认或草稿边界。 不自动批准发送。
图文/视频发布验收 检查待确认卡片是否显示平台、账号、素材和风险信息。 创建发布确认会话，验证发布动作被拦在待确认。 不调用真实发布 runner。
失败恢复 查看失败任务和重试任务是否能在记录里追溯。 人工制造一个失败任务，再创建重试任务并导出诊断。 不删除真实业务数据。

通过标准

  • 主系统可登录，核心页面不空白、不跳登录。
  • 评论、私信、微信草稿至少能创建任务，并在发送前进入确认或草稿安全边界。
  • 图文发布、视频发布必须创建待确认会话，不自动批准真实发布。
  • 失败恢复能看到失败原因、重试任务和下一步建议。
  • 证据导出能导出任务诊断包、会话证据和回复记录。
  • 失败项必须说明是账号未登录、平台预检失败、执行器缺失、页面元素找不到，还是业务代码错误。
