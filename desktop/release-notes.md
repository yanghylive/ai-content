## v1.1.72（2026-08-10）

本版完成炼刀竞品差距闭环与生产环境修复。

- 登录与云端能力统一走生产环境（kaypal.cn）：修复测试残留域名（KAYPAL_AUTH_BASE_URL 默认与本地配置从 test.kaypal.cn 切回生产；AI 网关与桌面证据浏览器标记同步补生产域；测试环境仍可显式 env 切回）。
- 新增 AI 网页代操作：自然语言指令驱动真实浏览器执行（打开/点击/输入/截图/提取/等待），逐步截图留证；支持 LLM 动作解析（配置默认模型后自动启用），失败自动降级规则解析；DISPATCH_MOCK 下硬失败防伪。
- 新增桌面悬浮球（hoverBall）：透明置顶小窗，随时唤起 AI 网页代操作，输入指令即执行并查看分步结果与截图证据；可拖拽，默认开启（hoverBallEnabled 关闭）。
- 新增 Token 用量追踪：每日配额（默认 200 万）/调用前预检/调用后上报，明细可追溯（/api/usage/token）。
- 新增门店 POI 管理：门店点位 CRUD + 按城市/分类聚合报告，对接探店内容场景（/api/poi）。
- 新增商品视频一键剪辑：商品信息自动生成带货口播文案（钩子/卖点/价格/CTA 分镜），一键提交成片（/api/video/product-copy、product-cut）。
- 群发计划新增默认配置查询端点；完成态列表走状态过滤。
- 后端全量自动化测试 1451 项全绿，验收门禁 PASS=50 FAILED=0。

本版继续对齐商用交互闭环，并完整保留现有导航、模块、字段和业务入口。

- 桌面授权会先创建并选中当前工作区，再进入业务页面；增长、CRM、应用安装和平台账号统一使用经过成员资格校验的租户上下文。
- 增长账号健康读取当前租户、当前用户在发布中心的全部账号，不再被旧占位记录遮挡。
- 视频号无法提取二维码时保留同一受控浏览器会话，等待网页登录完成后自动保存绑定结果。
- BaiLongma 本地语音运行时随桌面端真实监听 3721；只有服务在线且账号授权验证通过时才显示可用。
- Agent 工作台在没有可用模型时阻止新建、发送和重试；正常空产物不再冒成 500，真实服务错误仍会显示。
- 客服机器人新建流程改为本地草稿，取消不落库，明确点击保存才创建记录。
- 旧登录接口缺少请求体或字段时统一返回 400，不再触发服务端 500。
- Windows 真机测试候选连接当前已在线的 JIUZHANG AI 账号服务，修复授权码无法获取的问题。
- 桌面端按 Windows/macOS 真实平台登记授权设备，不再错误登记为 Web 设备。
- 本地 3011 后端始终随桌面应用启动；“自动恢复连接”只控制异常后的自动重连。
- v1.1.56 是真机测试候选包；正式发布前仍需上线生产账号域名、修复官网证书并完成 Windows 代码签名。
- RedFox 数据能力仍需租户安全配置合法 RedFox API Key；JIUZHANG AI 登录、套餐和积分不能替代第三方凭据。
- 短视频评论获客新增“创建并立即执行”和“保存并立即执行”，原有每天定时启动能力继续保留。
- 立即执行增加服务端一次性确认、重复点击保护和租户归属校验，不会把预览误当成真实触达。
- 浅色模式统一侧栏、顶部栏和导航层级配色，深色模式保持原有视觉与操作状态。
- 新增 AgentWaker 小红书运营助理与公众号运营助理，支持生成内容包、保留执行过程并在发布前等待人工确认。
- 公众号运营助理支持官方草稿写入与标题回读、正式发布前独立一次性确认和发布状态回查；失败会保留记录并禁止盲目重试。
- 平台授权不再向前端返回 Access Token，编辑时留空可保留原令牌；自定义发布地址只允许 HTTPS 白名单域名。
- 内容库 HTML 编辑与预览加入 no-referrer 和 iframe 脚本隔离，阻止预览内容主动执行脚本。
- 同步平台授权、公众号助理、小红书助理、内容库和 API 客户端的最新前端修正，真机安装包不再沿用 1.1.51 的旧构建。
- Windows 安装包不再在解压前启动阻断式 PowerShell 预检；必需运行时改由构建前和打包后守卫验证。
- 修复 Windows PowerShell 解析安装脚本失败，导致 Windows 10/11 在文件解压前被错误拦截的问题。
- 情报搜索只展示本次真实返回的数据，报告与任务运行链接可以恢复到指定记录。
- 增长任务统一为“预检、确认、真实执行”单一链路，结果区分完成、部分完成、失败与缺少证据。
- 微信任务补充逐对象结果和危险动作确认；Agent-S 主执行链、默认自动发送和三种操作模式保持不变。
- 设置与客户详情支持页签深链、错误重试和未保存修改提醒。
- Windows 安装包以 Win10 真机账号验收为当前放行标准，Win11 不在本轮验收范围。
