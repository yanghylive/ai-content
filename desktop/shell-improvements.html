01

调出机制：浏览器进「＋」菜单，快捷键常驻

P0
TraeWork 把浏览器当成顶部标签条里的一等公民。我们保留"按需展开"原则不变，但把「＋」做成浏览器式新建菜单，并给面板一个全局快捷键。
现状 — ＋ 直接新建业务标签，浏览器只能靠右下角悬浮球

03

地址栏体验：建议下拉 + 快捷站点 + 加载进度线

P0
对照 TraeWork 浏览器标签的地址行：聚焦即出建议，操作有反馈。我们的控制条目前只有一个裸输入框。
现状 — 纯输入框，无建议、无进度反馈

建议 — 聚焦出建议，空态给快捷站点，顶部一条进度线

建议项 = 最近访问 + 历史 + 搜索；快捷站点用你们业务的平台（抖音/小红书/公众号/视频号）而不是通用导航站。
04

面板底部活动条：把「控制台日志」搬进浏览器面板

P1
TraeWork 底部那条「控制台日志 · 清除」是它信任感的关键来源——Agent 干了什么随时可查。AI 代操作同样需要。
现状 — Agent 动作只出现在审批浮层里，批完即消失
（面板底部：什么都没有）
批过的动作、跳过的页面、失败的步骤——事后无处回看。
建议 — 30px 活动条，事件流 + 计数 + 一键清除，点击展开全量
▸ 面板活动 5清除
20:24打开 douyin.com/video/7498…
20:25Agent 点击「回复」· 已批准查看
20:26Agent 输入文字 · 等你批准去处理
默认收起为一行（高度 30px 不打扰），有待办时琥珀点 + 计数；与审批浮层共享同一事件源。
