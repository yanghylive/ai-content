## 1. 项目定位

JIUZHANG AI 内容创作平台是一套面向内容团队、销售运营和独立创作者的本地桌面 + Web 控制台系统，目标是把“找客户、做内容、发出去、看互动、再跟进”收进一个工作台。

当前交付重点不是营销页，而是可运行的业务系统：

- 内容生产：选题、内容生成、素材库、文章反抓、模板与风格。
- 发布中心：平台账号、发布任务、发布记录、合规确认、任务状态追踪。
- 客户与互动：客户列表、消息、真实互动执行入口、人工确认边界。
- 桌面运行：Electron 包内置前端静态产物、本地后端 SQLite bundle、Playwright 浏览器、Node runtime。
- 自动更新：Windows 安装包和 `latest.yml` 已上传到阿里云 OSS。

## 4. 架构概览

```text
用户
  ↓
Electron 桌面应用
  ├── Next.js 静态前端
  ├── 本地 NestJS API
  ├── SQLite 本地数据库
  ├── Playwright Chromium / CDP 控制能力
  ├── 微信 native runtime / DB helper
  └── electron-updater 自动更新
       ↓
阿里云 OSS generic update feed

开发/云端路径
  ├── frontend dev server: http://127.0.0.1:3010
  ├── backend API: http://127.0.0.1:3011/api
  └── GitHub Actions 发布安装包
```

关键边界：

- 前端只负责业务交互、状态展示和发起任务，不应直接绕过后端执行真实外部动作。
- 后端负责鉴权、任务、确认、账号、运行时调度、审计记录。
- 桌面端负责启动本地后端、承载浏览器自动化运行时、提供自动更新。
- 真实发布、真实互动、真实群发必须保留用户确认或明确授权边界。

## 12. 真实发布与真实互动边界

这些规则不要改：

- 真实发布不能被“任务创建成功”替代。
- 真实互动不能被“记录写入成功”替代。
- 涉及外部平台的发送、评论、私信、群发、加好友、朋友圈等动作，必须有用户授权或确认。
- 账号状态异常时不能假绿。
- 目标不明确时不能自动发。
- 内容有风险时必须进入确认或阻断。

工程交接重点：

- `local-engine` 可以协调权限、确认、状态、证据和审计。
- WeChat / 桌面真实交互路径不能绕开 Agent-S / local controller，除非用户明确要求改架构。
- 默认业务目标是 auto-send，但风险、目标不确定、权限缺失时必须转人工确认。

## 13. 常见问题排查

### 13.1 平台账号已登录但列表没显示

排查顺序：

1. 确认用户是否真的完成第三方登录窗口。
2. 点击平台页“刷新登录状态”。
3. 查真实桌面 SQLite，不要只查开发库。
4. 查 `publish_accounts` 是否新增。
5. 查 `growth_account_health` 是否把账号判成异常。
6. 查前端请求 `/api/local-bridge/accounts` 是否 200。
7. 查前端缓存或 modal 状态是否没有关闭。

### 13.2 发布任务显示未授权

通常含义：

- 还没有用户确认真实外部动作。
- 账号登录态未识别。
- 云端额度/权益冻结。
- 目标平台需要重新扫码或二次授权。
- 运行时不允许在当前状态下点击最终发布按钮。

不要把“未授权”当作纯 UI 文案问题，必须查确认记录、账号状态和权益状态。

### 13.3 自动更新看不到新版

排查：

```bash
curl -fsSL https://kaypal.oss-cn-hangzhou.aliyuncs.com/updates/latest.yml
```

确认：

- `version` 是否大于本机安装版本。
- `path` 是否指向真实存在的 `.exe`。
- 客户端 update feed 是否是 `https://kaypal.oss-cn-hangzhou.aliyuncs.com/updates/`。
- electron-updater 日志是否有下载/校验错误。

### 13.4 Windows 安装失败

排查：

- 是否被 Windows Defender / SmartScreen 拦截。
- 安装目录是否有权限。
- 旧版本进程是否未退出。
- 是否缺少 Node runtime、Playwright browser、Prisma engine、Sharp native dependency。
- 查看桌面端日志和安装器日志。
