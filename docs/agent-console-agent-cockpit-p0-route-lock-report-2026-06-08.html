允许进入 P1：GitHub UI 直接迁入。

进入 P1 后第一步不是写新设计，而是复制 GitHub 源码目录并完成最小编译适配。P1 完成标准是：新路由首屏能打开，视觉结构像 GitHub Canvas Agent，能用 mock state 展示左 Chat 和右 Canvas。
