## 四、测试方法关键经验（供后续回归测试复用）

1. **React 受控 input 必须用 CDP 真实键盘输入**：`Input.dispatchKeyEvent`（type=char）逐字符输入，React 的 onChange 才能可靠捕获。`el.value=` + `dispatchEvent('input')` 以及 `document.execCommand('insertText')` 均会被 React valueTracker 重置为空（textarea 不受影响，仅 input 受限）。
2. **列表页存在「搜索框」input，勿用 `querySelector('input')[0]`**：会误填搜索框。应按 placeholder 精确定位，如 `input[placeholder*='专业测评风']`。
3. **SPA 路由跳转后需等待**：`waitSel` 若匹配到旧页面的元素（如列表页搜索框）会立即返回，导致读到跳转前的旧 DOM。对跳转后的断言应加固定等待或等待新页面独有元素。
4. 工具：`cdp-drive.mjs`（多步交互驱动，新增 `type` 动作）+ `cdp-scan.mjs`（批量路由快照）+ `cdp-eval.mjs`（单步求值），位于 `.workbuddy/tools/`。
