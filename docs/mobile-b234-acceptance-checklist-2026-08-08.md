# 手机端真实验收检查单（B2/B3/B4）

> 版本：2026-08-08 ｜ 范围：仅手机端（APK WebView / PWA）
> 用途：桌面执行线（真实发布/互动/云端额度）跑完后，手机端按此单逐项验收。
> 前置：手机端 UI 代码已全部就绪（B2 权益展示 6e36d24b；B3 回读展示、B4 互动链路既有代码）。

## B2 云端额度/冻结一致性（手机端验收）

| # | 验收项 | 入口 | 预期 |
|---|---|---|---|
| 1 | 权益状态区展示 | 我的 tab（套餐卡下方） | 显示方案（免费版/Pro）+ 状态徽标（正常/额度冻结/已逾期/已过期）+ 到期时间 |
| 2 | 冻结提示 | 同左 | 状态=冻结/逾期/过期时：红色提示「⚠️ 额度受限期间，发布与采集可能失败」+ 「去查看与续费 →」（跳 /settings） |
| 3 | 正常态 | 同左 | 免费版：「当前免费方案：发布/采集入口可用（商用执行需升级 Pro）」；付费：「权益正常，可正常发布与采集」 |
| 4 | 数据来源 | GET /api/billing/status | entitlement.status 与云端真实冻结状态一致（不出现假成功） |

## B3 真实发布回读（手机端验收）

| # | 验收项 | 入口 | 预期 |
|---|---|---|---|
| 1 | 发布统计真实 | 发布 tab | 「成功 N / 失败 N / 待回执 N」与真实发布结果一致（非假成功） |
| 2 | 任务列表回执状态 | 发布 tab 任务列表 | 每条任务状态：成功（有平台回执）/ 失败（失败原因）/ 待回执（等待外部结果） |
| 3 | 回读证据链 | 任务详情 / 证据中心（tasks/evidence） | 证据类型含「平台回执」「结果确认记录」，展示外部结果回读明细（readback_json） |
| 4 | 连续回归 | 发布 tab | 连续 20 次真实发布：成功/预期失败均有回读证据，假成功率 0 |
| 5 | 失败恢复 | 失败任务 | 失败原因明确 + 重试入口（重发布需桌面端，手机端引导「去电脑端处理」） |

## B4 真实互动闭环（手机端验收）

| # | 验收项 | 入口 | 预期 |
|---|---|---|---|
| 1 | 互动授权 | 互动任务发起 | 高风险互动有授权确认（interaction-approval） |
| 2 | 人工确认 | /tasks/confirmations | 待确认列表出现该互动任务，可「确认发送」 |
| 3 | 执行记录 | 任务列表/详情 | 执行后有任务 ID + 状态流转（等待确认→执行中→完成/失败） |
| 4 | 回读证据 | 任务详情 | 外部执行结果回读（成功/失败 + 证据） |
| 5 | 审计 | 证据中心 | 互动记录可追溯（dispatch/审计记录） |
