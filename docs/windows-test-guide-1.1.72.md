## 0. 测试环境准备

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 **x64**（不要用 ARM64 虚拟机；微信 4.x x64 二进制在 ARM64 模拟下不可信） |
| 微信 | **微信 4.x 桌面版已登录**（测试通讯录/群发/朋友圈必需） |

**安装**：双击 Setup exe 安装（可覆盖旧版，数据不丢）→ 打开应用 → 登录。

## 6. 已知边界

- **Win11 不在本轮验收范围**（以 Win10 真机为准，同 1.1.67 约定）
- 安装包**未签名**（代码签名待官网证书完成后补）；Windows SmartScreen 可能提示，选择"仍要运行"
- AI 网页代操作需要登录态 session（悬浮球自动带主窗口 cookie）
- 悬浮球开关：设置 `hoverBallEnabled`（默认 true）
- studio_core 成片引擎需独立部署（8610），未部署时 product-cut 返回降级
