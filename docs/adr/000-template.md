## ADR 写作准则（单人项目特别）

1. **写给未来的协作者看**——不是自己看。假设半年后第一个新人加入，他必须能 only 读 ADR + README 上手。
2. **末尾留 "Reviewer" 空白**——未来回填。即便单人也假装有 reviewer，强制 second-thought 习惯。
3. **超过 3 个月不动的决策**——季度复盘时确认状态：Accepted 还有效？还是 Superseded？
4. **不写"为什么这样好"，写"为什么没那样"**——拒绝的方案比选中的方案信息量大。
