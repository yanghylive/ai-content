# 安卓 App 真机测试指引（APK 0.1.3）

> 2026-08-10 · APK：`mobile/dist/JIUZHANG-AI-0.1.3-线上.apk`（versionCode 4，含批次 A/B/C 全部适配）
> 支持 Android 8.0+（minSdk 26），目标 SDK 35

---

## 一、安装

1. **传包到手机**：APK（6.2MB）通过微信/QQ 文件传输/数据线拷贝到手机，或直接扫码/网盘下载
2. **安装**：点开 APK → 允许「安装未知来源应用」（华为/小米/OPPO/vivo 需在设置里放开"外部来源应用"或点"仍要安装"）
3. 打开 **JIUZHANG AI**（图标 label 为 JIUZHANG AI，包名 com.aicontent.desktop.mobile）
4. 登录：手机号/扫码登录线上账号

## 二、重点测试清单（对应刚完成的适配项）

| 测试 | 预期 | 说明 |

| 首页/内容/消息/我的 底部 Tab | 切换正常 | 移动端五 Tab |

## 四、ADB 联调（可选，开发用）

手机开 USB 调试，连接电脑：
```bash
adb install -r <apk路径>          # 装包
adb logcat -s JIUZHANG            # 看 App 日志（壳已把 H5 console 转到这里）
adb shell am start -n com.aicontent.desktop.mobile/com.aicontent.mobile.MainActivity
```
