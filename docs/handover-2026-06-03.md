## 3. 完整登录流程（device flow）

### 3.1 用户体验

1. 打开 `http://localhost:3010/login`
2. 点"用 Kaypal 账号登录"
3. 后端调 `test.kaypal.cn/api/desktop-auth/start` 拿 `deviceCode` + `userCode` + `verificationUrl`
4. UI 显示：
   - "去 `verificationUrl` 输 `userCode`"（userCode 大字可点击复制）
   - 5 秒轮询一次 `/poll`
5. 用户在 Kaypal 网页输码、点确认
6. 后端 `/poll` 拿到 `status: authorized` 和 `access_token`
7. 后端用 token 调 `getUserFromDesktopToken` → 拿 Kaypal 用户信息
8. 后端找/建本地 user（用 `kaypalUserId` 关联），建本地 session，设 cookie
9. 前端跳转到 `nextPath`（默认 `/`）

### 3.2 Fallback（device flow 失败时）

UI 自动切到"本地账号密码"表单（用 `authApi.login`，本地 PG 账号 `admin / test1234`）。**不是** Kaypal 凭据。

### 3.3 真实测试中我拿到的响应

```
POST /api/kaypal/desktop-auth/start
{
  "deviceCode": "dev_kJc4MjugcFDMtohUYIDaIWD0z4JIXRJM",
  "userCode": "KAYP-FRZ3",
  "verificationUrl": "https://test.kaypal.cn/api/desktop-auth/authorize?device_code=...&user_code=KAYP-FRZ3",
  "expiresIn": 600,
  "interval": 2
}
```

后端 `start` 和 `poll` 都**调通云端**返 200。`profile/devices/subscription` 返 401 是因为没 Bearer token（用户得去 Kaypal 网页授权后才拿得到）。

## 7. 怎么跑端到端验收

### 7.1 基础健康
```bash
curl -i http://localhost:3010/login       # 200
curl -i http://localhost:3011/api/auth/setup-status  # 200
curl -i http://127.0.0.1:5409/health     # 200
```

### 7.2 跑完整 device flow
```bash
# 1. start
curl -X POST http://localhost:3011/api/kaypal/desktop-auth/start \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"test","deviceName":"AI Content Workbench","platform":"web"}'
# 拿到 deviceCode + userCode + verificationUrl

# 2. 用户去 verificationUrl 输 userCode 点确认

# 3. poll
curl -X POST http://localhost:3011/api/kaypal/desktop-auth/poll \
  -H "Content-Type: application/json" \
  -d '{"deviceCode":"<从 step 1 拿>","deviceId":"test"}'
# status: pending → 等用户授权
# status: authorized → 自动建 session
```

### 7.3 跑商用 Gate
```bash
# 1. 登录拿 session token
TOKEN=$(curl -s -X POST http://localhost:3011/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"test1234"}' \
  -c cookies.txt | python3 -c "...")
COOKIE=$(grep ai_content_session cookies.txt | awk '{print $7}')

# 2. 跑 gate
COMMERCIAL_SESSION_TOKEN="$COOKIE" \
COMMERCIAL_COOKIE_HEADER="ai_content_session=$COOKIE" \
node scripts/commercial-acceptance-gate.mjs
```
