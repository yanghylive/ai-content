> 状态:已定稿(2026-09,经多轮视觉迭代 + 协调性审计 + 真机验收)
> 适用范围:九章桌面端(≥768px)主导航左侧 rail 图标体系
> 代码位置:`frontend/src/components/shell/rail-icons.tsx`(RailIcon + ThemeToggleIcon)
> 样式位置:`frontend/src/components/shell/desktop-vp.css`、`shell.css`

---

## 1. 设计决策历史(为什么是现在这样)

本套图标经历了 5 个版本,每轮结论都应视为约束,避免回退:

| 版本 | 方案 | 被否原因 |
|---|---|---|
| v1 品牌点线性 | 24 网格线性描边 + 右上角渐变点 | 仍是普通线性图标,「不够高级」 |
| v2 渐变印章 | 实心渐变方章容器 + 白形镂空 | 背景色块不好看 |
| v3 无底实心剪影 | 去容器、纯实心图形 | 重绘后丢失细节,「不如以前」 |
| v4 方案A图形去底 | 保留 A 图形,无背景块 | ——(此版图形被认可) |
| **v5 方案A金点亮(当前)** | **无容器 + 第二层细节 + 激活金渐变** | —— |

**核心结论(不可回退)**:
1. **不要给图标加任何背景容器/色块**(方章、渐变块都试过,均被否)。
2. **图标主体图形本身要有"第二层细节"**(趋势线、领口 V、文字行、已读勾、进度条、屏内容条等),这是"精致感"的来源。
3. **激活态用「点亮」而非「贴块」**:图标主体由灰变金渐变,配合指示条与文字变色。
4. 金色(而非紫)是 rail 深紫黑底上的激活色——与桌面「磨砂紫金」主题同族,醒目且不撞品牌紫。

## 2. 设计文法(必守)

### 2.1 网格与尺寸
- SVG `viewBox="0 0 24 24"`,渲染尺寸 **24px**(rail 场景按钮内),`aria-hidden` + `focusable=false`。
- 全部面性图形(fill),无 stroke 主图形;仅内部细节线用细 stroke。

### 2.2 无容器
- 任何状态(激活/未激活/hover)都不画背景方块、圆角章、渐变底。
- 图标与文字的层级关系由 rail item 的背景 hover 与激活色表达,不由图标自绘容器表达。

### 2.3 细节层次(每枚图标两层的结构)
- **第一层(主体)**:一个一眼可读的整体造型(柱 / 人像 / 文档 / 气泡 / 卡片 / 平板 / 星 / 人像)。
- **第二层(内部细节,统一反白或半透明)**:
  - growth:上升趋势折线 + 端点圆点
  - customer:领口 V 切(主客)+ 右后第二人(半透明)
  - content:两行文字 + 右下探出笔尖
  - interaction:三点 + 底部已读双勾
  - execution:顶部进度条 + 完成勾
  - device:摄像头点 + 三行屏幕内容条
  - assistant:中心点 + 右上伴星(半透明)
  - mine:领口 V 切
- 细节在 22-24px 渲染下仍应清晰可辨;若一枚细节过多导致糊,收敛到 2 个以内细节元素。

### 2.4 状态
| 状态 | 图标 | 文字 | 指示条 | 背景 |
|---|---|---|---|---|
| 未激活 | `currentColor`(灰) | rail muted | 无 | 透明 |
| hover | 同左(颜色随文字提亮) | 变亮 | 无 | `--kx-paper-soft` 轻提示 |
| **激活** | **金渐变 `#f0b45c → #c9811f`**,内部细节反白 | `--kx-gold` | 金色竖条 `--kx-gold` + 光晕 | **无**(禁止渐变块) |

- 内部细节:激活 `#ffffff` 不透明;未激活 `currentColor` 且 `opacity .32`。

## 3. 色彩(与主题 token 对齐)

rail 恒为深紫黑底(`desktop-vp.css` 定稿,亮暗一致):
`linear-gradient(180deg, #1c1431, #110c1e 88%)`

激活金与主题变量:
- 图标渐变:`#f0b45c → #c9811f`(硬编码于 rail-icons,与主题切换钮共用同款渐变定义)。
- 指示条/激活文字:改用 **`--kx-gold`**(亮 `#e39a3e` / 暗 `#eebd72`),**不要**再用 `--kaypal-v3-accent`(紫)——审计发现同屏"金块+紫字+紫条"是最大不协调。
- 顶栏 logo 保持品牌紫渐变(135deg `#722ed1 → #531dab` 桌面),与金色激活图标是「品牌紫 + 点缀金」关系,同屏不冲突。

**对比度提醒**:暗色下金 `#eebd72` 或渐变中段在深紫黑底上足够醒目;若未来改动,任何激活色须在 `#1c1431` 底上满足 WCAG AA(文字)与可辨识(图标)。

## 4. 8 枚图标语义(勿改语义)

| railName | 场景 | 图形语义 |
|---|---|---|
| growth | 今日增长 | 三柱渐升 + 趋势线(持续爬升) |
| customer | 客户管理 | 客户群体(主客 + 后位客) |
| content | 内容运营 | 创作(文档 + 笔尖) |
| interaction | 互动中心 | 对话(气泡 + 消息点 + 已读) |
| execution | 执行中心 | 自动化完成(卡片 + 勾) |
| device | 设备任务 | 设备(平板 + 屏内容) |
| assistant | 助手 | AI 生成(四角星 + 伴星) |
| mine | 我的 | 个人(人像) |

新增场景图标必须沿用同一文法:无容器、两到三个元素、可辨认语义、勿用 Lucide/IconPark 线性图形直接充当 rail 图标。

## 5. 使用方式(代码契约)

```tsx
import { RailIcon, type RailIconName } from "@/components/shell/rail-icons";
import { ThemeToggleIcon } from "@/components/shell/rail-icons";

// 普通场景
<RailIcon name="growth" size={24} active={activeScene === "growth-home"} />

// 助手下沉入口、我的(注意:我的 = settingsOpen 或 mine 路由时激活)
<RailIcon name="mine" size={24} active={mineActive} />
```

要点:
- `active` 必须由调用方给出真实状态;**「我的」按钮**在展开设置面板时也要 `active`(见 app-shell 的 `mineActive`)。
- 尺寸传 24;如未来调整须同步检查 `desktop-vp.css` rail item 布局,勿只改 size。
- 主题切换钮用 `ThemeToggleIcon`,渐变与图标同款金,不用普通线性 sun/moon。

## 6. 与全局图标体系的分工(协调性结论)

- 页面正文、功能卡图标:**IconPark outline**(48 网格线性)。
- 壳内功能性图标(顶栏搜索等):`ShellIcon`(线性)。
- **rail 专属品牌图标:RailIcon(面性、细节、金点亮)** —— 它是全局唯一的「面性 + 渐变点亮」语系,属有意为之的主导航强化,不要把它推广到正文区,也不要让正文线性图标混入 rail。

## 7. 验收清单(改图标后自查)

- [ ] 无任何背景容器/色块(激活与未激活)。
- [ ] 激活:金渐变主体、白色细节、指示条金色、无渐变底。
- [ ] 未激活:灰、第二层细节仍隐约可见(不可糊成一团)。
- [ ] 深浅主题 / hover / 激活四态都过一遍。
- [ ]「我的」开面板时点亮(不在 mine 路由时也亮)。
- [ ] 22px 与 24px 渲染均清晰(细节不糊)。
- [ ] 与正文线性图标同屏不打架(粗细/风格分层正确)。
- [ ] typecheck + eslint + build 通过。
