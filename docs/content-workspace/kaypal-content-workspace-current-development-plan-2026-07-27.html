前端 UI 工作面

第一波：编辑器核心交互

这组是 UI 密度最高的，建议同一位主程连着做。

  • 自动保存状态
  • 保存失败与冲突恢复
  • AI 候选 diff / 接受 / 拒绝 / 撤销
  • 版本恢复

第二波：内容追溯和门禁

这组偏结构和信息架构，适合另一路并行推进。

  • 素材 / 品牌 / 知识引用
  • 多平台版本任务
  • 审核门禁和原地修复

第三波：入口映射和回归

把旧入口与五步任务流的对应关系补全，确认灰度过程中入口不丢失。
