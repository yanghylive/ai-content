每阶段验收口径

  1. S3：真实 48 小时观察完成，关闭/10%/回滚三态都有证据。
  2. UX-07 / UX-08：编辑过程不丢正文，候选交互明确，版本恢复可用。
  3. UX-09 / UX-10 / UX-11：引用可追溯，多平台独立，审核门禁能拦住高风险。
  4. UX-02：旧入口还在，五步任务流映射完整，功能没有少。
  5. 最终回归：截图、测试、决策、合同状态和交付说明一致。
