## Drift correction

G1.1 reopened the brief, outline confirmation and responsive action contract after the earlier source-only checks missed four semantic problems.

- Brief values now carry field-level provenance. A changed value is persisted as `source=user`, `label=已由你修改`, `edited=true`.
- Outline confirmation is a server-owned operation bound to a SHA-256 digest of the current items. Client timestamps and hashes cannot confirm an outline.
- Local rule preview is explicitly disclosed as fixed text logic and never creates a formal optimization version.
- Narrow layouts expose one save action and one context-appropriate primary progression action.

## Astryx evidence

The local Astryx CLI (`0.1.7`) was queried for Button, Field and Layout guidance. The implementation follows the retrieved principles: one primary action per view, field helper/status descriptions, and a fixed footer with a scrollable editor body. The application remains on HeroUI because `CW-D003` is still open; Astryx is design evidence rather than an installed React component library.
