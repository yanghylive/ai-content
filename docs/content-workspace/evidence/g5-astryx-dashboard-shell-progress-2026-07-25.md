# G5 Astryx dashboard shell progress - 2026-07-25

Status: `in_progress`

## Implemented

- The authenticated dashboard render tree now uses Astryx `AppShell`, `TopNav`, `SideNav`, `SideNavHeading`, `SideNavItem`, and the AppShell-managed mobile navigation.
- Desktop and mobile navigation are generated by one recursive adapter over the existing `createSectionItems()` data.
- Only the active business group starts expanded; inactive groups stay collapsed without removing any route.
- Desktop collapse/expand is exposed in `TopNav` with explicit Chinese state labels, outside the Next.js development overlay area.
- Mobile navigation is controlled by the shell and has an explicit Escape fallback in addition to Astryx native dialog handling.
- The legacy hand-built mobile overlay, Escape handler, focus restoration, and duplicate responsive sidebar rendering were removed from the active layout.
- Authentication, tenant switching, account actions, release notes, solution-run context, business-tool entry panels, and page children remain wired to their existing logic.
- The migration guard now fails if the dashboard returns to the legacy Sidebar import or loses the required Astryx shell imports.
