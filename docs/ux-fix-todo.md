# UX 整改待办（按优先级，可直接照做）

## P1 · 错误提示人话化
- [ ] local-engine 同步失败异常文案翻译成人话：
  - 「请稍后重试」→ 按失败层给可执行引导（微信未登录 / 版本不兼容 / 窗口不在通讯录页 / 组件未就绪）
- [ ] 联系人页失败态加「导出排查资料」按钮（复用 diagnostics/export 接口）
- 验收：同步失败时用户能照提示自助，而非反复重试

## P1 · 开发者文案排查
- [ ] 全局搜面向用户报错里的内部术语（「模型配置」「管理员」「provider」「platform」）
- [ ] 统一改成「你该做什么」句式
- 验收：无面向普通用户的内部术语报错

## P2 · 组件下载进度可见
- [ ] 前端首次触发微信功能时，调 readiness 接口，显示「组件准备中 / 下载进度」
- [ ] 下载失败给可理解的降级说明，不静默
- 验收：用户能分辨「在等」还是「坏了」

## P2 · 登录态过期主动引导
- [ ] AI 调用失败且检测到授权过期 → 提示「去账号与设备重新登录」
- 验收：过期时给重登引导，不静默吞错

## P3 · 新旧版合并
- [ ] HybridRoute 隐藏「旧版完整功能」标签，只留低调返回入口
- 或：把 legacy 功能合并进 v2
- 验收：用户无感知新旧并存

## P3 · 默认文字输入
- [ ] AI 助手 inputMode 按平台区分：桌面默认文字、移动默认语音
- 验收：桌面端默认文字输入框

## 第二轮补充（12:15）

### P1 · AI 对话历史持久化
- [ ] AI 助手 items 会话历史持久化（localStorage 或后端会话表），刷新/重启后恢复
- 验收：刷新页面后之前的对话还在，不用重新交代背景

### P1 · AI 工具结果可验证
- [ ] 工具执行完成（tool_exec → done）后，在对话里给「查看结果」跳转（如已建工作流→跳工作流页/查线索→跳线索页）
- 验收：用户能一键验证 AI 说「已开流水线」是真的

### P2 · 配额耗尽引导兑换
- [ ] 「今日 AI 对话次数已用完」提示里，若有返利余额，引导「可用返利兑换 AI 额度」+ 兑换入口
- 验收：用户知道怎么增加额度，而不是只能等明天

### P3 · 微信「随机抽样」术语口语化
- [ ] 「随机抽样同步」标题改口语（如「快速试同步」），保留现有 desc
- 验收：普通用户不用查字典就知道两个选项区别
