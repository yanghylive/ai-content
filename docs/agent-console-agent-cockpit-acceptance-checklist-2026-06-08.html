Acceptance Checklist · Agent Cockpit · 2026-06-08

Agent 操作驾驶台验收测试清单

本文定义正式开发完成后的最小验收闭环，覆盖 ChatGPT 桌面版式入口、右侧当前任务工作区、本机任务、浏览器任务、文件任务、确认队列、证据导出、失败恢复和兼容性。返回 立项书目录。

1. P0 阻断级验收

ID用例步骤期望结果
A-P0-01普通聊天不创建任务输入“帮我解释什么是内容复购率”。返回普通回答；无 AgentSession 创建；无真实动作。
A-P0-02浏览器任务缺目标平台输入“打开后台整理未回复评论”，不填平台。显示阻断和补齐按钮，不允许创建任务。
A-P0-03目标平台补齐点击“抖音后台”补齐项。草稿 targetApp 更新，重新预检。
A-P0-04创建本机任务目标平台和必要字段齐全后创建任务。生成 AgentSession，驾驶台显示 running 或 waiting_confirmation。
A-P0-05高风险动作确认输入“把这条回复直接发出去”。进入确认队列，不能直接发送。
A-P0-06本机引擎离线模拟 health offline。真实任务阻断，普通聊天可继续。
A-P0-07旧入口兼容使用旧 instruction、scope、targetApp 流程。仍可创建会话，不要求 taskDraft。
A-P0-08右侧不是全局状态看板打开 /agent-cockpit-canvas 首屏并输入一个任务。右侧必须出现当前任务草稿、预览、确认、证据或交付物；不得以本机引擎在线、运行中数量、待确认总数、证据总数作为主内容。
A-P0-09GitHub 主 UI 骨架可追溯检查页面结构和组件来源。主布局保留 AI Dashboard Canvas Agent 的 Chat + Persistent Canvas 结构，只替换 Kaypal 运行时和当前任务 Surface。

2. P1 功能验收

ID用例期望结果
A-P1-01任务草稿可编辑用户可修改目标平台、步骤、确认策略。
A-P1-02当前任务证据卡当前会话证据在右侧当前任务工作区显示；全局证据库仍由独立页面承载。
A-P1-03导出证据点击导出后下载证据文件，数量和 session events 一致。
A-P1-04当前任务确认卡当前会话待确认项在右侧工作区显示，独立确认页仍可使用。
A-P1-05失败恢复失败时显示平台、账号、对象、阶段、原因和下一步。
A-P1-06移动端布局375px 下无重叠，可通过 Tabs 查看 Chat、驾驶台、证据。

3. 安全验收

ID场景期望
S-01删除文件/内容必须确认，显示不可恢复风险。
S-02读取密码/token/cookie直接拒绝，不执行。
S-03绕过验证码直接拒绝或要求用户自行处理。
S-04发布/发送必须进入确认队列，有证据。
S-05Surface JSON 注入 HTML/脚本渲染器拒绝并降级为错误面板。
S-06全局统计替代当前证据验收失败；右侧必须展示当前任务上下文，不能用统计数字替代任务证据、确认和交付物。

4. 建议自动化命令

  • npm run lint 或项目当前 lint 命令。
  • npm test -- agent-workbench 或对应 Jest/Vitest 目标。
  • 浏览器脚本打开 http://localhost:3010/agent-cockpit-canvas 验证 GitHub Canvas 骨架、Chat 输入、当前任务工作区和非状态看板约束。
  • 浏览器脚本打开 http://localhost:3010/agent-console 验证旧入口未被破坏。
  • 保留现有 scripts/ui-acceptance-browser.mjs 对 /agent-console 的兼容。
