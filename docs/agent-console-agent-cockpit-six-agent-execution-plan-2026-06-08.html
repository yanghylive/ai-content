Execution Plan · 6 Agents · 2026-06-08

Agent 操作驾驶台 6 智能体专家协作开发计划

本计划用于约束后续实际开发，避免再次跑偏。核心规则是：主 UI 必须直接迁入 GitHub ai-dashboard-canvas-agent 的 Chat + Persistent Canvas 源码骨架，Kaypal 只做运行时替换、当前任务工作区、Surface 安全治理和业务适配。

硬门禁：不得重新手写一个“看起来像 GitHub 项目”的 UI；不得恢复旧 /agent-cockpit-lab；不得直接改原 /agent-console；每个开发步骤前必须完整读 9 个开发文档。 右侧 Canvas 不得做成全局状态看板，不得重复 /local-engine、/confirmations、任务记录、证据库已有页面。
开发原则防跑偏门禁、直接迁入策略。 6 个智能体专家角色、职责、输入输出。 阶段路线4 周 20 个工作日拆解。 迁入映射GitHub 文件到 Kaypal 文件。 任务清单每阶段细任务、负责人、工期。 验收门禁每步进入下一阶段前必须过。 风险控制跑偏、依赖、安全、兼容风险。 协作节奏每日同步、交付格式和回滚规则。

1. 开发原则

主 UI 原则

Direct Migration
  • 以 GitHub ai-dashboard-canvas-agent/src/app/page.tsx 为页面骨架。
  • 以 GitHub components/chat/* 作为左侧 Chat 入口。
  • 以 GitHub components/dashboard/* 作为右侧 Persistent Canvas；Canvas 的业务语义必须改成当前任务工作区。
  • 保留原项目布局、组件拆分、卡片结构和视觉比例，先不做 Kaypal 风格重绘。

适配原则

Kaypal Adapter
  • CopilotKit、AG-UI、Google ADK 只作为被替换运行时，不作为首期依赖引入。
  • Kaypal 适配只接当前任务需要的 localEngineApi、AgentSession、Confirmation、Evidence。
  • Agent 输出 UI 必须走 KaypalAgentSurface 白名单，不能透传 HTML/脚本。
  • 真实动作必须进入任务草稿、预检、确认、证据闭环。
  • health、browserStatus、sessions、confirmations 只能作为当前任务预检、阻断、Surface 数据源，不作为主 UI 统计面板。
停止条件：如果某一步无法证明“该 UI 文件直接来自 GitHub 项目或是必要适配层”，则暂停，不继续写代码。

2. 6 个智能体专家分工

6. 每阶段验收门禁

P0 路线锁定门禁

D1-D2
  • 9 个文档已读，且在阶段报告中列明。
  • GitHub 迁入映射表已确认。
  • 新路由、禁止触碰路径、回滚路径明确。

P1 UI 迁入门禁

D3-D5
  • 页面结构来自 GitHub page.tsx。
  • Chat/Dashboard 组件目录来自 GitHub 源码迁入。
  • 页面不是 Kaypal 后台壳，不显示 Kaypal 左侧导航。

P2 当前任务工作区门禁

D6-D10
  • Canvas 首屏是当前任务工作区空态，不是全局状态看板。
  • Chat 输入一个任务后，Canvas 能生成任务草稿/预览/确认/证据/交付物中的至少一种 Surface。
  • health、browserStatus、sessions、confirmations 只作为当前任务信号或跳转入口。
  • 不新增后端强依赖，不破坏旧接口。

P3 治理闭环门禁

D11-D15
  • 普通聊天不创建任务。
  • 浏览器任务缺平台会阻断并可补齐。
  • 高风险动作进入确认队列，不直接发送或发布。

P4 发布候选门禁

D16-D20
  • npm run lint 对相关文件通过。
  • 浏览器打开新路由，桌面和 375px 移动端无明显重叠。
  • /agent-cockpit-lab 不存在或不作为目标页。
  • /agent-console 原流程保持可用。
  • 最终 diff 只包含计划内文件。

7. 风险控制

风险触发信号处理策略负责人
再次变成手写仿版 UI新增大量自定义布局但无法对应 GitHub 源文件。立即停止开发，回到迁入映射表，删除仿写文件。A1 + A2
CopilotKit/ADK 依赖阻塞编译lint/build 报缺包或 provider 缺失。保留组件结构，替换运行时为 Kaypal adapter。A3
Surface 安全越界出现 HTML、script、iframe、shell、token 字段。渲染器拒绝并降级错误面板。A4
破坏旧 /agent-console旧路由 git diff 或验收失败。回滚旧路由相关改动，新驾驶台保持独立。A5
页面只在代码里可用，浏览器不可用未打开页面或页面红屏。A6 必须做浏览器验收后才能进入下一阶段。A6
右侧变成状态看板主内容出现运行中数量、待确认数量、证据总数等全局指标。立即回滚该 UI，改为当前任务 Surface；全局指标只能作为当前任务阻断提示或跳转入口。A1 + A3 + A6

8. 协作节奏和汇报格式

每日节奏

Daily
  • 开始前：A1 确认 9 文档已读和本日目标。
  • 开发中：A2/A3/A4/A5 分别提交小范围 diff。
  • 结束前：A6 执行最小验证闭环。
  • 每日冻结：说明哪些在本地、哪些已同步、哪些未验证。

每步汇报格式

Required
  • 本步读了哪些文档。
  • 本步迁入了哪些 GitHub 源文件。
  • 本步哪些是 Kaypal 必要适配。
  • 改了哪些文件。
  • 验证结果和剩余风险。
  • 下一步是否允许继续。
最终目标不是“做一个新后台页面”或“状态监控页面”，而是把 GitHub Agentic Canvas UI 作为 Kaypal 当前任务工作区：Chat 提出目标，右侧持续生成和操作当前任务的草稿、预览、确认、证据和交付物。
