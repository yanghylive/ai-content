## 三、关键技术决策记录

1. **手机端 ≠ 电脑端逻辑**：平台互动改造为「调起 App + 一键转发」半自动（用户拍板），RPA 全自动作为深度演进（已完成模拟器闭环）。
2. **D2 微信群发/朋友圈下线**：合规评估（腾讯风控封号风险高）→ 用户拍板「文档写明不支持 + 前端入口全移除」，8 路由改「暂不支持」提示页。
3. **D3 P1 链接曝光**：发现后端 viral/analyze 早已存在（文档滞后），仅补前端转发闭环。
4. **套餐判定真相**：PlanGuard 读 `tenant_entitlements` 表（DB 持久化授权），不是 `/auth/me` 的 kaypalPlan 展示字段——之前「大壮 FREE 会被拦」判断有误，实际大壮是 ADVANCED。
5. **C2 权益收敛**：24 个文件分散判断 plan → 全部收敛到「DB 授权优先」语义（local-engine + voice 两处真实判定）。
6. **部署坑根治**：macOS openrsync（protocol 29）与云端 rsync 3.1.3（protocol 31）不兼容 → 装 GNU rsync 3.4.4（protocol 32）根治；后续发布不再踩坑。
