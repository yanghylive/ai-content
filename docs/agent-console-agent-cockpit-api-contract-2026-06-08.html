API Contract · Agent Cockpit · 2026-06-08

Agent 操作驾驶台数据合同

本文定义任务草稿、Surface、阻断补齐、确认、证据和当前会话投影的数据合同。右侧 Canvas 只消费当前任务数据，不消费全局状态聚合。返回 立项书目录。

1. AgentTaskDraft

type AgentTaskDraft = {
  schemaVersion: "agent.task-draft.v1";
  id: string;
  source: "chat" | "preset" | "manual";
  originalInstruction: string;
  title: string;
  taskType:
    | "general_chat"
    | "content_generation"
    | "comment_reply"
    | "browser_operation"
    | "file_operation"
    | "remote_check"
    | "publishing";
  executionScope: "browser" | "desktop" | "local-files" | "remote" | "mixed" | "chat-only";
  targetApp?: string;
  targetAccountId?: string;
  riskLevel: "low" | "medium" | "high";
  requiresConfirmation: boolean;
  steps: Array<{ id: string; title: string; description?: string; requiresConfirmation?: boolean }>;
  missingFields: Array<"targetApp" | "account" | "permission" | "file" | "instruction_detail">;
  approvalPolicy?: AgentApprovalPolicy;
};

2. KaypalAgentSurface

type KaypalAgentSurface = {
  schemaVersion: "kaypal.agent.surface.v1";
  id: string;
  surface:
    | "task_draft"
    | "approval_panel"
    | "evidence_list"
    | "browser_status"
    | "browser_preview"
    | "publishing_preview"
    | "file_analysis_result"
    | "execution_timeline"
    | "delivery_result";
  props: Record<string, unknown>;
  actions?: AgentSurfaceAction[];
};
禁止 props 携带 HTML、脚本、事件处理器字符串、外部 iframe 地址或任意代码。browser_status 只能表达当前任务的预检、阻断和补齐信息，不能作为全局浏览器健康面板。

3. Blocker Resolution Actions

type AgentBlockerResolutionAction = {
  id: string;
  label: string;
  kind:
    | "set_target_app"
    | "select_account"
    | "open_route"
    | "refresh_health"
    | "request_permission"
    | "edit_instruction";
  payload?: Record<string, string | number | boolean>;
};

原 LocalEngineActionBlocker 增加可选 resolutionActions，旧前端忽略该字段仍可运行。

5. 当前会话投影

type AgentSessionProjection = {
  sessionId: string;
  status: AgentSessionStatus;
  title: string;
  scope: "current_task";
  currentStep?: string;
  progressLabel?: string;
  blockers: LocalEngineActionBlocker[];
  confirmations: AgentConfirmation[];
  evidence: AgentEvidence[];
  deliverables: AgentDeliverable[];
  nextActions: AgentSurfaceAction[];
};

该投影只代表当前对话正在推进的一个任务。全局运行中数量、全局待确认数量、全局证据总数、全部 session 列表不进入右侧 Canvas 主状态；需要查看时跳转到既有独立页面。

6. 兼容要求

合同兼容策略
新增字段全部可选，后端未支持时前端降级到旧版表单。
schemaVersion所有新结构必须带版本号，便于后续迁移。
Surface props前端逐字段校验，不透传到 DOM 危险属性。
全局状态health、browserStatus、sessions、confirmations、evidence 只能投影为当前任务预检、阻断、确认卡或证据卡，不能直接渲染成全局数字看板。
错误响应保留原 error message，新增 failureContext 可选字段。
