### 3. [P2] Token 双套断言口径（E1）
复核结论成立，清单 E1 原文「17 个均双套、共 34 处」不准确。实测（`globals.css`，引入提交 `bc5db55e`）：

- 新增 17 个 token、共 **32 处**定义：
  - **15 个主题语义色**在 `:root` 与 `.dark` 各定义一次（30 处）：
    `bg / danger-border / danger-ink / hover / muted-soft / panel / primary / success-border /
    success-ink / surface / surface-2 / surface-hover / warning / warning-ink / warning-soft`；
  - **2 个非主题 token 仅 `:root` 定义**（2 处）：`--kaypal-v3-radius-md: 14px`、
    `--kaypal-v3-font-display: 32px`。
- 处理决定：**不补 `.dark` 副本**。尺寸/字号 token 与主题无关，`:root` 定义后经 CSS 变量继承
  进入 `.dark`；既有约定即 `.dark` 从不重复 radius/字号 token（dur/ease/space/font/radius 全族
  均仅 `:root`）。已在清单修订记录中修正 E1 口径为「15 语义色双套 + 2 继承 token」。
