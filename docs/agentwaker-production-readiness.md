# AgentWaker 生产收尾清单

当前结论：双渠道非真机开发范围已经完成，本地运行与生产 bundle 验证通过。真实平台认证仍未完成；当前工作树包含大量既有未提交改动，因此在形成干净 Git 基线前只能称为 release candidate，不能签正式生产版本。

## 代码与版本

- [ ] 双渠道核心目录已纳入 Git，干净检出可构建（当前有 656 个既有脏工作树条目，未擅自整体提交）
- [x] Prisma PostgreSQL 与 SQLite schema、迁移和旧库升级测试一致
- [x] 生产 bundle 由当前源码重新生成并做启动冒烟
- [x] 版本号、构建产物、数据库 schema hash 和验收报告已绑定到 `agentwaker-release-manifest-2026-07-21.json`

## 可靠性

- [x] AgentWaker run 的文章、会话和确认单具备事务与失败补偿
- [x] 模型、图片和上传请求支持 AbortSignal，超时会取消底层请求
- [x] 发布写入具备确定性幂等键和远端对账恢复
- [x] 账号、文章、任务和发布记录按明确工作区隔离
- [x] 进程重启后 running、readback_pending、publishing 状态有明确恢复策略

## 安全

- [x] 发布账号与 JPage Token 使用 AES-256-GCM 信封加密，桌面密钥持久化并限制文件权限
- [x] API 响应、日志、错误和诊断证据均不返回凭据
- [x] 账号删除、JPage 私有上传、远程渲染确认、草稿写入和正式发布均使用服务端一次性确认
- [x] HTML、URL、重定向、私网地址、JPage/微信域名白名单检查为 fail-closed
- [x] 默认无人值守真实执行和后台队列关闭，发布守卫检查默认值

## 运维

- [x] 健康接口能报告数据库、角色包、队列和增长开关状态
- [x] 失败、卡死、远端状态未知和凭据过期均有可操作的页面状态或日志
- [x] SQLite 在线一致性备份与完整性验证已演练：10,584,064 bytes，72 张表
- [x] 有一键停服、重建和重启命令；数据库回滚使用已验证 SQLite 备份
- [ ] 灰度运行一周无 P0/P1，完成操作培训和故障演练
