Agent 操作驾驶台安全与权限规则

本文定义 Agent 驾驶台真实动作的权限、确认、阻断、证据和禁止事项。返回 立项书目录。

1. 安全原则

  • Chat 回复不等于用户授权真实操作。
  • 涉及外部发布、发送、删除、改文件、账号敏感操作必须确认。
  • 所有真实操作必须关联 AgentSession，并沉淀事件和证据。
  • 驾驶台不能绕过商业权限、试用限制、账号权限和本地引擎安全边界。
  • 模型输出只做建议和 UI 描述，最终动作由受控 API 执行。
  • 右侧 Canvas 只展示当前任务的草稿、预览、确认、证据和交付物；不能用全局状态数字替代任务证据和决策信息。

2. 风险分级

等级动作类型处理规则
低风险问答、写作、总结、生成草稿、不触达外部系统。可直接执行，保留聊天记录。
中风险打开浏览器、读取页面、分析本地文件、生成待发布内容。需要预检环境；可创建任务；关键步骤留证据。
高风险发布、发送、删除、修改文件、远程配置、账号切换、批量操作。必须进入确认队列，展示后果和目标对象。
禁止读取密码/cookie/token、绕过验证码、私自付款、隐藏上传敏感文件、执行任意代码。直接阻断，展示原因和替代建议。

3. 必须确认的动作

动作确认面板必须展示证据要求
发布图文/视频平台、账号、标题、内容摘要、发布时间、可见范围。发布前预览、发布结果截图或回执。
发送评论/私信回复平台、账号、对象、原评论、拟发送内容。发送前内容、发送后状态。
删除/覆盖内容对象名称、影响范围、不可恢复风险。删除前对象截图、执行日志。
修改本地文件文件路径、修改摘要、备份策略。diff 摘要、备份或写入结果。
远程服务操作服务名、环境、动作、影响范围。请求摘要、返回结果、日志。

4. 阻断规则

  • 本地引擎离线：阻断真实任务，允许普通聊天。
  • 浏览器任务缺目标平台：阻断创建，给出平台补齐按钮。
  • 平台账号未登录或过期：阻断执行，跳转账号与设备或运行检查。
  • 商业权限不足：阻断执行，展示权限原因，不伪装为普通失败。
  • 用户未确认高风险动作：任务进入 waiting_for_confirmation。
任何“自动发送”“直接发布”“删除”“覆盖”“批量处理”类指令，即使用户在自然语言里写了，也必须通过受控确认流程。任何把右侧 Canvas 做成全局状态看板、隐藏当前任务确认和证据的实现，也视为安全验收失败。

5. 证据规则

证据类型适用场景最低要求
screenshot浏览器/桌面操作关键页面前后至少一张。
page_snapshot读取页面数据保留摘要，不保存敏感 token。
stage_log多步骤任务每个关键阶段有标题和时间。
failure_reason失败任务说明平台、账号、对象、阶段、原因和下一步。
artifact生成文件/内容有文件名、类型、来源会话。
证据不是可选装饰，是 Agent 驾驶台能被信任的基础。右侧只展示当前任务证据；全局证据检索、批量导出和历史审计继续留在独立证据页面。
