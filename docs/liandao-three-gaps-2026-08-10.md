# 炼刀 vs JIUZHANG AI · 三项差距报告（代码量/质量 · 商业化验证 · 功能结果）

> 2026-08-10 · 基于炼刀 dt-ai-helper 1.8.5 asar 反解与 JIUZHANG 当前仓库实测
> 诚实口径：不把"我们代码多"当胜利，也不回避"炼刀已验证"的事实。

---

## 一、代码数量

| 维度 | 炼刀（1.8.5） | JIUZHANG（当前） | 对比 |
|---|---|---|---|
| 渲染端源码 | 191 个 JS 文件 / **5,774 行**（Vite 压缩产物） | — | — |
| 后端源码 | 主进程 1.65MB **bytenode 字节码**（不可读，估计等效 3-5 万行）+ 本地 Python 桥接服务（未反解） | **580 个 TS 文件 / 256,799 行** | — |
| 前端源码 | 含在 191 文件中 | **695 个 TS/TSX / 191,962 行** | — |
| 合计可审计源码 | ~5.7K 行（压缩）+ 字节码（黑盒） | **~448K 行 TS**（全部可读可审计） | 我们 ~78 倍（仅算可审计部分） |
| 路由/端点 | 274 IPC + 188 可见路径 | **523 controller 路由** + 171 映射 | 我们 1.9 倍 |

**口径说明**：炼刀用字节码保护主进程（反逆向），可见源码仅渲染端压缩产物；我们全部 TS 明文。差异部分来自技术路线（字节码 vs 开源），部分来自产品广度（我们 9 平台发布 + 浏览器自动化 + AI 员工工作流）。

## 二、代码质量

| 维度 | 炼刀 | JIUZHANG | 判定 |
|---|---|---|---|
| 语言/类型 | TS 编译（renderer），主进程字节码黑盒 | **TS strict**（ignoreBuildErrors 已关），tsc --noEmit 全绿 | 我们领先 |
| 自动化测试 | **asar 内 0 个测试文件** | **134 spec / 1464 tests** 全绿 | 我们显著领先 |
| 数据层 | **lowdb JSON 文件** | **Prisma + Postgres/SQLite**（106 model，migration 体系） | 我们领先 |
| 架构 | Electron + 本地 Python 桥（IPC REST 风格） | **NestJS 模块化**（523 路由，mixin/controller/service 分层） | 我们领先 |
| CI/CD | 无可见 CI | **5 个 workflow**：quality-gates / build-windows / release-desktop / demo-guard / content-workspace-contract | 我们领先 |
| 发布守卫 | 无可见 | 版本同步检查、资源白名单 verify-oss-release、release-size 检查、Windows 构建守卫 | 我们领先 |
| 密钥管理 | 未见 | **KAYPAL_CREDENTIAL_MASTER_KEY + safeStorage** 系统安全存储 | 我们领先 |
| 防伪设计 | 无可见 | **DISPATCH_MOCK 硬失败**（不能伪造发布成功） | 我们领先 |

**结论**：代码质量维度我们全面领先（类型安全、测试、数据层、CI、发布守卫、防伪）。炼刀的字节码保护是"反逆向"不是"质量"。

## 五、综合结论

```
代码数量：  🟢 我们领先（~448K 行 TS 可审计 vs 5.7K 行压缩 JS + 字节码黑盒）
代码质量：  🟢 我们领先（strict/1464 tests/Prisma/5 CI/发布守卫/防伪）
商业化验证：🔴 炼刀领先（已交付 1.8.5，有真实客户循环；我们待 Windows 真机 + 生产运行）
功能结果：  🟡 我们能力面更宽（171 路径全覆盖、9 平台），但炼刀已验证、我们待真机；
           唯一实质功能缺失 = 手机操控（无 adb/scrcpy）
```

**差距本质**：
1. **质量/数量不是差距，是优势**——真正的差距在"验证"：炼刀是**已验证的商业产品**，我们是**代码/打包/门禁就绪、待真机与生产证明**的准商业产品。
2. 唯一功能级缺失是**手机操控**（P2 独立立项）。
3. 补差距的路径很明确：**Windows 真机验收（微信 8 能力 + 新包 1.1.72）+ 浏览器账号扫码验收（9 平台发布）+ 生产运行时间**——这三步走完，商业化验证维度即追平。
