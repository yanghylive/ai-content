## D. 核心缺口（复核主发现）

**「真实发送一条回复给真实客户」全链至今 0 环境验证通过。** 拆解：

| 环节 | 到达度 | 缺口 |
|---|---|---|
| 关键词搜索→读评论（scan） | 本机推至平台风控边界 | 小红书=自动化环境被风控（website-login/error）；kuaishou=ERR_ABORTED；**需真机** |
| 线索评分→AI 生成回复 | 代码在（C 类），本轮验证模式故意挡住（minLeadScore=999 只读） | 生产链路未在面板环境下端到端跑过 |
| 回复写回（发送/草稿） | 闸门 fail-closed 拒绝路径已验证；**自动批放行路径未验证过一次真实发送** | 需面板桥在线 + 真实账号 + 关闭只读门槛的受控验证 |
| 私信（DM）获客 | 契约字段债（TD-1）已在案 | 未动 |

**即：主线商业价值 =「一个真实客户收到 AI 的回复」这件事，从未被端到端证实。** 基建（隔离/闸门/审计/守护/安全）全部就绪，缺的是最后一步受控真实发送验证。
