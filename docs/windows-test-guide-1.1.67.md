# JIUZHANG AI 内容创作平台 v1.1.67 Windows 测试指引

> 测试对象：`JIUZHANG AI 内容创作平台 Setup 1.1.67.exe`（Windows x64，NSIS 安装包）
> 测试目的：验收 **计费统一**（费 token 的 AI 能力全部走 kaypal.cn 云端订阅账户 + 积分结算）与核心链路回归

---

## 0. 测试环境准备

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 **x64**（不要用 ARM64 虚拟机） |
| 微信 | 微信 4.x 桌面版已登录（测试通讯录同步） |
| 账号 | **kaypal 云账号**（手机号/邮箱登录；本地手机号账号无云权限，AI 能力会提示重新登录） |
| 网络 | 能访问 `test.kaypal.cn`、`dashscope.aliyuncs.com` |

**安装**：双击 Setup exe 安装（覆盖旧版即可，数据不丢）。安装后打开应用 → 登录 kaypal 账号 → 「账号与设备」确认云端已接通。

---

## 1. 重点验收：AI 能力计费统一（本次核心）

> 验证方式：每个功能用一次，然后到 **kaypal.cn 云端控制台 → 账户 → 用量/积分流水** 确认有对应扣费记录。
> 验收标准：**所有 AI 调用都在云端积分流水里能查到**，本地不再有"免费跑"的通道。

| # | 功能 | 操作路径 | 预期结果 | 通过 |
|---|---|---|---|---|
| 1.1 | 语音转文字（ASR） | 语音助手中心 / 侧边栏 AI 助手 → 点麦克风说话 | 语音识别为文字，进入对话 | ☐ |
| 1.2 | 文字转语音（TTS） | 语音面板 → 输入文字 → 合成 | 播放合成音频 | ☐ |
| 1.3 | AI 生图 | 素材中心 → AI 生图 → 输入描述 → 生成 | 生成图片入素材库 | ☐ |
| 1.4 | AI 配音 | 素材中心 → AI 配音 → 输入文案 → 生成 | 生成音频入素材库（可播放） | ☐ |
| 1.5 | 对话/文章创作 | 侧边栏 AI 助手 → 提问 | 正常流式回复 | ☐ |
| 1.6 | 生视频（数字人） | 素材中心 → AI 生视频 | 提交成功，可查询进度 | ☐ |

**计费断言**（测试 1.1–1.6 后）：
- 云端积分流水出现对应记录（ASR/TTS/生图/配音/视频各至少一条）
- **积分不足时**：应提示"云积分不足，可用返利现金抵扣"，且**不会免费放行**
