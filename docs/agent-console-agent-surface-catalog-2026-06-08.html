Kaypal Agent Surface Catalog 白名单

本文定义 Agent 可生成的当前任务 UI 面板白名单、字段、允许动作和安全限制。Surface 服务右侧当前任务工作区，不服务全局状态看板。返回 立项书目录。

1. 基本原则

  • Agent 只能选择 surface 类型并填 props，不能生成任意组件、HTML、CSS、脚本。
  • 所有 action 都必须映射到前端已实现的处理器。
  • 高风险 action 必须声明 requiresConfirmation: true。
  • Surface 只表达 UI 意图，不直接执行副作用。
  • Surface 必须绑定当前对话或当前任务；不得输出全局运行状态、全局任务数量、全局证据数量作为主内容。
禁止 Surface 中出现 dangerouslySetInnerHTML、iframe URL、script、onclick 字符串、shell 命令、令牌、cookie、本地绝对敏感路径。

2. Surface 白名单

Surface用途关键 props允许动作
task_draft展示可编辑任务草稿。title、taskType、executionScope、targetApp、steps、missingFields、riskLeveledit_field、select_account、create_session
approval_panel展示待确认动作和风险。title、description、riskLevel、target、consequence、requiredChecksapprove、reject、open_confirmations
evidence_list展示截图、页面快照、日志、文件证据。items、sessionId、exportableopen_evidence、export_evidence
browser_status展示当前任务所需浏览器账号和连接预检。online、readyAccounts、expiredAccounts、targetApp、blockingReasonopen_local_engine、select_account、refresh
browser_preview展示当前任务涉及的浏览器页面、对象和下一步。targetApp、pageTitle、objectSummary、nextStep、requiresUserInputopen_browser、refresh、create_followup_task
publishing_preview展示即将发布或发送的当前任务内容预览。platform、account、title、contentPreview、visibility、riskLeveledit_field、approve、reject
file_analysis_result展示文件总结、表格、提取结果。fileName、summary、sections、deliverablessave_result、create_followup_task
execution_timeline展示任务步骤和事件。events、currentStep、statuspause、continue、stop
delivery_result展示最终交付结果。title、summary、links、artifactsopen_result、export_evidence、continue_task

3. Action 白名单

Action说明是否可副作用确认要求
edit_field修改前端草稿字段。否无需确认
select_account打开账号选择。否无需确认
open_browser打开当前任务关联的浏览器或页面。是读取/浏览无需确认；发布/发送仍需确认
refresh刷新当前任务预检或预览。是无需确认
create_session创建本机 Agent 会话。是中高风险任务前置确认
approve批准待确认动作。是必须展示风险和检查项
reject拒绝待确认动作。是无需二次确认
pause暂停任务。是无需确认
continue继续任务。是如继续包含高风险动作则确认
stop停止任务。是无需确认
export_evidence导出当前证据。是无需确认
不允许新增 metrics_panel、global_status、engine_dashboard 这类 Surface。需要查看全局状态时，只能提供跳转动作，不能把右侧 Canvas 改成监控页。

  "schemaVersion": "kaypal.agent.surface.v1",
  "id": "surface-task-draft-1",
  "surface": "task_draft",
  "props": {
    "title": "整理抖音未回复评论",
    "taskType": "comment_reply",
    "executionScope": "browser",
    "targetApp": "抖音后台",
    "missingFields": ["account"],
    "riskLevel": "medium",
    "steps": [
      {"id": "s1", "title": "打开抖音后台"},
      {"id": "s2", "title": "读取未回复评论"},
      {"id": "s3", "title": "生成建议回复"},
      {"id": "s4", "title": "等待确认后发送", "requiresConfirmation": true}
    ]
  },
  "actions": [
    {"id": "a1", "kind": "select_account", "label": "选择抖音账号"},
    {"id": "a2", "kind": "create_session", "label": "创建任务", "requiresConfirmation": false}
  ]
}
