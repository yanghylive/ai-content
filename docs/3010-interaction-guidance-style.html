3010 INTERACTION GUIDANCE · UI PLAYBOOK

不要说“加个弹窗”
要说清楚用户会经历什么

这是一份给产品、设计、前端和 WorkBuddy 共用的视觉指导样式。每个示意都回答四个问题：什么时候出现、从哪里出现、用户怎么操作、完成后页面变成什么。

47组件词典
7描述公式
1统一状态语言
组件

先选类型

Tooltip、Popover、Modal、Drawer 不按“好不好看”选择，而按信息量和是否打断选择。

状态

再说变化

明确 idle、loading、success、error、timeout，以及按钮是否禁用和是否可重试。

设备

最后说设备

桌面保留上下文，手机优先 Bottom Sheet；不能让移动端依赖 hover、滚轮或精细拖拽。

08 · 统一护栏

所有页面都要遵守，避免指导样式变成另一种装饰性模板。

真实状态

没有真实进度就不用百分比；错误和超时必须可见。

风险确认

发布、群发、外触达、权限、删除先展示影响再确认。

可访问

支持键盘、Esc、焦点返回、ARIA 和 reduced-motion。

可回滚

拖拽失败、请求失败、执行中断都要保留恢复或重试入口。
