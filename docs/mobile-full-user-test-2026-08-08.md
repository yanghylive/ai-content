### 2. 内容 Tab（/content）⚠️→✅
- 页面结构：6 宫格入口（选题/AI创作/素材库/文章反抓/模板风格/视频成片）+ 全部草稿（共 16 篇）+ 最近草稿 3 篇 + 素材库概况
- **交互验证**：新建 → /content/articles（内容生成页，16 篇草稿）✅ → 新建 → /content/workspace?create=true（内容工作室）
- **⚠️ Bug 发现（P1，已修复待部署）**：内容工作室报「内容服务暂时不可用」
  - 根因：`GET /api/articles?page=1&limit=60` 返回 **14.6MB** 响应（16 篇文章，`xiaohongshuData` 每篇 700KB~1MB 的 base64 卡图，合计 12MB+）
  - 前端 `withTimeout` 12s 超时（WebView 传输 body 需 8s+ 且不稳定，加上 JSON.parse 大对象）
  - 修复：`articles.service.ts findAll` 加 `select` 排除大字段（xiaohongshuData/rawHtml/finalHtml/workspaceBrief/workspaceOutline/wechatData），payload 降至 KB 级；32/32 后端测试通过
  - 影响面核对：手机端所有 list 消费方（内容页、内容工作室、发布流）只用摘要字段，安全
